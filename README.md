# Week 8: Books Assignment

A simple Node.js and Express project for practicing file handling and building a Books API.

## Features
- Save and read books using JSON files.
- Display book details and total book count.
- Get all books or find a book by ID.
- Filter books by genre.
- Handle missing books with a 404 error.

## Technologies
- Node.js
- Express.js
- JSON

## How to Run

```bash
npm install
node saveBook.js
node readBook.js
node saveBooks.js
node readBooks.js
node server.js
```

Open `http://localhost:3000` to test the API.
